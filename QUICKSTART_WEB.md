# YouTube Downloader Web Application
# Quick Start Guide

## 🚀 Getting Started

1. **First Time Setup:**
   ```bash
   ./setup.sh
   ```

2. **Start the Web Application:**
   ```bash
   ./start_web.sh
   ```

3. **Open in Browser:**
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:5000

## 🎯 Quick Tips

- **New Chat**: Click the "New Chat" button in sidebar
- **Search Videos**: Type query like "funny cats" or "python tutorial"
- **Select & Download**: Click videos to select, then hit "Download Selected"
- **View History**: Click "Download History" in sidebar to see all downloads
- **Adjust Settings**: Click "Settings" to configure video quality, AI options, etc.

## 🛑 Stopping the Application

Press `Ctrl+C` in the terminal where you ran `start_web.sh`

## 📝 Quick Reference

### CLI Mode (Original)
```bash
./run_downloader.sh -q "search query" -n 5
```

### Web Mode (New)
```bash
./start_web.sh
```
Then use the browser interface at http://localhost:3000
