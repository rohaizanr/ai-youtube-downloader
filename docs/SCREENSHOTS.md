## Take Screenshots After Running

To add real screenshots:

1. Start the app: `./start_web.sh`
2. Use the interface
3. Take screenshots (Cmd+Shift+4 on Mac)
4. Replace placeholder links above with actual screenshots
5. Or add images to a `docs/screenshots/` folder

## Quick Screenshot Guide

```bash
# Create screenshots directory
mkdir -p docs/screenshots

# Take screenshots and save them:
# - docs/screenshots/chat-interface.png
# - docs/screenshots/sidebar.png
# - docs/screenshots/download-history.png
# - docs/screenshots/settings.png
# - docs/screenshots/video-card.png
```

Then update this file with actual image links.
